# Выбор локации для бурения скважины

**Задача.** Добывающая компания выбирает регион для бурения скважин. Нужно определить регион с максимальной суммарной прибылью и минимальным риском убытков.

**Что сделано.** Обучение моделей линейной регрессии, оценка качества, bootstrap-анализ прибыли и рисков по трём регионам, выбор региона и обоснование решения.

**Стек.** Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn, PHIK
